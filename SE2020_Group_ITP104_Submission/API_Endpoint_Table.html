CALIDI Boutique: API Endpoint Specification

1. User Management (Member 01)

MethodEndpointDescription
POST/api/auth/signupUser Registration
POST/api/auth/loginUser Login (JWT)
GET/api/auth/meProfile & Loyalty Info

2. Product & Inventory (Member 02)

MethodEndpointDescription
GET/api/productsPublic Catalog
POST/api/admin/productsAdd New Product
PUT/api/admin/products/:idUpdate Stock/Price

3. Order & Payment (Member 03)

MethodEndpointDescription
POST/api/ordersCreate New Order
POST/api/orders/:id/payProcess Payment
GET/api/ordersUser History

4. Delivery & Logistics (Member 04)

MethodEndpointDescription
GET/api/admin/deliveriesDelivery Schedule
POST/api/admin/deliveries/:id/assignAssign Rider
PUT/api/admin/riders/:id/approvalApprove Rider
